# Portfolio fonts

Self-hosted Latin WOFF2 subsets of the typefaces used by [Louder](https://trylouder.ai/), retrieved from Google Fonts on 16 September 2026.

| File | Family | Style / weight |
| --- | --- | --- |
| `geist-latin.woff2` | Geist | Normal, variable 100-900 |
| `geist-mono-latin.woff2` | Geist Mono | Normal, variable 100-900 |
| `instrument-serif-latin.woff2` | Instrument Serif | Normal, 400 |
| `instrument-serif-italic-latin.woff2` | Instrument Serif | Italic, 400 |

All three families use the SIL Open Font License 1.1. Each family's notice is included here. Files were downloaded unmodified; no runtime font service is required. Fallback families handle characters outside the Latin subsets.

Upstream font and licence sources:

- [Geist](https://github.com/google/fonts/tree/main/ofl/geist)
- [Geist Mono](https://github.com/google/fonts/tree/main/ofl/geistmono)
