# Portfolio fonts

Self-hosted Latin WOFF2 subsets, retrieved from Google Fonts. The site uses Poppins (retrieved 3 October 2026). Geist, Geist Mono, and Instrument Serif are the [Louder](https://trylouder.ai/) typefaces (retrieved 16 September 2026); they remain for `docs/brand-digest.html`.

| File | Family | Style / weight |
| --- | --- | --- |
| `poppins-400-latin.woff2` | Poppins | Normal, 400 |
| `poppins-500-latin.woff2` | Poppins | Normal, 500 |
| `poppins-600-latin.woff2` | Poppins | Normal, 600 |
| `geist-latin.woff2` | Geist | Normal, variable 100-900 |
| `geist-mono-latin.woff2` | Geist Mono | Normal, variable 100-900 |
| `instrument-serif-latin.woff2` | Instrument Serif | Normal, 400 |
| `instrument-serif-italic-latin.woff2` | Instrument Serif | Italic, 400 |

All four families use the SIL Open Font License 1.1. Each family's notice is included here. Files were downloaded unmodified; no runtime font service is required. Fallback families handle characters outside the Latin subsets.
